# あーやんYOLOスタ 32-06 ダイエット企画 最新修正版

## 挿絵

3P・4P・5P・6P・11P・13Pの本文挿絵を調整。
人物は添付「イラストテイスト一覧」内の実際の女性を単体素材化して使用。ボブの髪・点の目・小さい口・丸い輪郭と細いピンク線を維持。スマホ操作・ノートも一覧の実素材を使用。カレンダーと時計は既存の形を保ち線を細くした単体SVGへ変更。表紙の白アイコンは既存表紙フォーマットとして保持。

- 背景透過の単体PNG／SVGをimg要素で配置
- 輪郭・小物・髪・手足を切らない
- 人物と小物の線色は#DE5C84
- 既存の挿絵配置枠を維持。文字や写真を動かしていない
- 一覧画像をCSS背景として切り取る方法は使用していない
- 使用素材は素材/挿絵/へ保存

## 8P

右4枠の2行セットを上へ11px移動。見えている文字の上余白と下余白を計測してほぼ均等化。番号丸との接触を避け左右余白も自然にするため文章全体を左へ16px微調整。枠サイズ・位置・番号・文字サイズ・行間・文言・動画・タイトル・下部文章は維持。

その他の1P・2P・7P・9P・10P・12P・14P・15Pは前版と同一。
