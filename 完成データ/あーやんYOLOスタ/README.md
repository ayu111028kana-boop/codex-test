# あーやんYOLOスタ 32-06 ダイエット企画 最新修正版

参考画像のデザイン・レイアウト・挿絵サイズ感を取り入れ4Pと5Pを調整。2ページは独立したまま。全15Pと現在の内容を維持。

## 4P 自分の発信スタイルに合った企画を考える

- 左右同寸560×460pxの枠で「見出し→本文→大きな挿絵→補足」を統一。
- 中央に220pxの独立した挿絵領域を確保。
- 並走型は同じ肩回しを一緒に行う2人の女性。単にスマホを持つ人物ではなく一緒に取り組む様子を表現。
- お手本型はノートを持ち指を立てて教える女性。添付参考画像から挿絵だけを単体素材化。
- 両側の線画は実際に見える高さが約180pxとなるよう調整。枠内高さの約4割で主要要素として配置。
- 補足文は参考画像と同じ淡いピンクの丸い帯へ。下部結論は枠外中央を維持。

## 5P 企画を始める前に決める4つのこと

- 横一列の4枠を同寸275×400pxに統一。
- 「番号＋見出し／中央の大きな線画／下部の説明」の共通3段構成。
- 企画ノートとペン・カレンダーと時計・スマホ操作・告知メガホンをそれぞれ配置。参考画像の実際の線画を単体化し使用。
- 4点とも線画そのものの高さを約130pxへ統一。枠内高さの約3分の1で見えるサイズ。
- 淡いピンクの説明欄を同じ高さ・同じ位置へ配置。
- 番号丸・見出し・挿絵・説明文の中心線を共通化。文言はすべて維持。

参考画像を完成スライドとして貼っていない。文字・枠・ピンク帯・番号・単体挿絵はHTML上の独立要素。上下グラデーション・タイトル位置・ピンク点線・基本フォント・配色・ページ順を保持。他13ページは変更していない。
