# あーやんYOLOスタ 32-06 ダイエット企画 最新修正版

最新版をベースに指定11ページだけを調整。2P・4P・11P・12Pは変更していない。

| ページ | 今回の変更 |
|---|---|
| 1P | ダイエットジャンルを2行目と同じ52pxに統一。中央配置を維持 |
| 3P | 信頼関係づくりと差別化を同寸の枠内へ。枠上にピンク丸＋白字の番号を配置 |
| 5P | 番号を枠上へ配置。ピンク見出しを1行化。補足文を枠下の同一基準線へ整列 |
| 6P | 見出し→中央の挿絵→説明に統一。下部を「自分もフォロワーさんも無理なく続けられることが大事」へ変更 |
| 7P | 画像と4行を少し縮小して上へ移動。Canvaの補足文を下部結論のさらに下へ配置 |
| 8P | 番号をピンク丸＋白字へ。1段目の見出しに対応する位置へ統一 |
| 9P | 左右の枠内を縦中央に配置し上下余白を均等化 |
| 10P | 原画像をトリミングせず拡大。8P動画に近い縦長のサイズ感へ。右結果カードを縮小し上下余白を確保 |
| 13P・14P | 共通のピンク丸＋白字番号へ。大きさとページ上の縦位置を統一 |
| 15P | 指定の3文へ変更。1行・左揃えを維持。同幅820pxの背景を中央に配置し右余白を縮小 |
