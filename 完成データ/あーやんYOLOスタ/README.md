# あーやんYOLOスタ 32-06 ダイエット企画 最新修正版

今回の変更は番号デザインと12Pの横並び化のみ。

- 3P・5P・8P・13P・14P：ピンク丸の中に白字の1〜4。直径46px・数字28pxに統一。丸の中心を各枠の横中央と上辺へ一致させて半分重ねる。文言は維持。
- 8P：縦の4項目に共通の枠・上辺中央の丸番号を適用。番号が前後の文章に重ならないよう項目配置・行間を調整。文字サイズ・動画・タイトル・下部文章を維持。
- 12P：参加報告→返信・励ましを横並びへ。同寸306×190pxの2枠を同じ高さに配置。左右各2行・中央揃え。矢印の中心を枠の縦中央へ一致。左DM素材・上部強調文・下部2行を維持。

その他の1P・2P・4P・6P・7P・9P・10P・11P・15Pは変更なし。全15Pを維持。

## 検証

全15Pを1440×810で描画して目視確認。番号の直径・文字サイズ・枠中心との一致を測定。8Pの丸番号と文章の重なりなし。12Pの枠サイズ・上端下端・矢印中心を測定。指定外9ページのPNGは前版と完全一致しPDFも元ページを保持。配色・フォント・上下グラデーション・タイトル点線を保持。安全領域・文字のはみ出し・動画再生・ページ送り・PDFページ数・ZIP整合性を確認。
