# あーやんYOLOスタ 32-06 ダイエット企画 最新修正版

今回の追加微修正は5Pと8Pのみ。

## 5P 企画を始める前に決める4つのこと

- 枠ごとに文字量で変わっていた内部の列幅を共通の1列へ固定。挿絵・見出し・説明文の横中心を各枠の中央に統一。4枠共通で上44pxの見出し・中央150pxの挿絵・下70pxの説明領域を設定。
- 領域間の間隔を16pxにそろえて内容全体を少し上へ調整。
- 1行と2行で説明文の中心がずれないよう共通領域の縦中央へ配置。
- 4枠の外寸・見出し・挿絵・説明領域の高さと基準線を照合。
- 文言・挿絵素材・文字サイズ・番号・枠デザインを保持。

## 8P スタンプカードの参加方法

- 丸番号を各枠の上辺から少し上へ移し本文との距離を確保。丸は枠上辺に自然に重なる状態を維持。
- 各枠を高さ96px・段間17pxへ統一。本文2行の見た目の上下余白がほぼ20pxずつになるよう調整。
- 見出しと補足文の間を3→5pxへ広げて読みやすく整理。
- 4枠とも番号・見出し・補足の相対位置を共通化。
- 動画・タイトル・下部文章・文言・文字サイズは維持。

全15Pを維持。その他13ページは変更していない。全体のフォント・配色・上下グラデーション・タイトル点線・ページ順を保持。

## 完成ファイル

- あーやんYOLOスタ_全15P.pdf：全15ページ
