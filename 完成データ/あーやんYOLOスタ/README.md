# あーやんYOLOスタ 32-06 ダイエット企画 最新修正版

最新版4P・5Pを固定の基準として3P・6P・11P・13P・14Pだけ挿絵と必要範囲のレイアウトを調整。全15Pを維持。

## 今回の変更

- 3P：差別化を「プロフィールを見せて手を振る女性」で表現。人物とプロフィールの組み合わせで覚えてもらう意味を補助。見える高さ175pxと広い横幅で存在感を確保。左DM画像の元データ・表示位置・寸法は完全維持。左右の見出しを整列し右枠内を整理。
- 6P：頻度はカレンダーと時計。期間は期限の日付からゴールの旗へつながるカレンダーへ。両方とも線画そのものの高さ140pxに統一。左右の同寸枠で見出し→大きな挿絵→説明の順に配置。説明文は4P・5Pと同じ淡いピンクの欄へ。
- 11P：トレーニングは一緒に肩回しをする2人。アフタートークは吹き出しとリラックスした女性へ。見える高さ175pxに統一。見出し・本文・大きな挿絵の基準線をそろえ下部2行との余白を調整。
- 13P：報告が届くスマホ→紹介するメガホン→やってみようとアイデアを持つ女性の流れ。実際の線画の高さ145pxへ統一。3枠の番号・見出し・挿絵・説明の位置を共通化。
- 14P：スマホで声が届く→発信者が紹介→別のアイデアを思いつく女性を追加。線画の高さ145pxに統一。13Pと同じ外寸・番号・見出し・挿絵領域を使い流れを自然につなぐ。引用文と補足文はすべて維持。

人物はボブ・点の目・小さい口・丸い輪郭・少ない髪の線に統一。単色#DE5C84の線画を透明な単体PNGで配置。輪郭や小物を切らずobject-fit:containで表示。

1P・2P・4P・5P・7P・8P・9P・10P・12P・15Pは変更していない。4P・5Pは今回の固定基準。実画像が主役の7P・8P・10P・12Pへ挿絵を追加していない。全ページの文言・ページ順・タイトル位置・点線・上下グラデーション・基本配色を維持。
