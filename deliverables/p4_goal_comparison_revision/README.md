# 4P ×・○のゴール比較図（全11枚）

基準：p4_start_context_revision。ユーザー共有の4P図解と最終修正指示を基に4Pだけ変更。
既存のタイトル・点線・上下帯・書体・配色を継承し、薄い背景とピンク枠の左右比較に整理。

左：×例「結婚記念日までに痩せたい」→目標だけだと他人事になりやすい。
右：○例 スタート「太って、夫からの愛情表現が減った」↓ゴール「結婚記念日までに痩せて、夫にもう一度惚れられたい」。
下部：「×＝目標だけ」「○＝背景＋目指す未来」。

4Pは考え方の比較に絞り、セイウチの話や過去・現在・出来事の詳細は追加しない。5Pは元のまま。
PPTXの変更エントリはslide4.xmlだけ。HTMLも4Pのみ。ほか10ページのPDF描画とPNGは元版と一致。全11枚。HTMLの文字はみ出しなし。PPTXもPDFへ変換して表示確認。
