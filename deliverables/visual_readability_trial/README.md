# 視覚化・読みやすさ改善 試作版（全11枚）

本版は完成版の全面改修ではなく、最新のp4_spacing_pink_gradient_revisionを基準にした別名の試作。1P・2P・7P・9Pは一切変更しない。

## 参照した制作キット

最初に添付AGENTS.mdを読み、デザインルールPDFと文字入れ領域PDFを確認。その後、デザインルール.md、挿絵ルール.md、テンプレート.html、追加ルール記入用.md、CLAUDE.md、README.md、はじめに.md、AIへの依頼文.md、完成データを保存.mdを確認。完成見本「自分の強みを見つけよう」「ジャンル決め時に知っておいてほしいこと」と需要リサーチ法PDF、共有された挿絵・構成見本も参照。今回の個別指示を優先し、対象外ページや既に確定した写真・文言は維持した。

## 各ページの視覚化と理由

|ページ|何を視覚化したか|選択理由|
|---|---|---|
|3P|2人とハート・つながりの矢印|発信者と視聴者が関わり、一緒に変化を見届けることを1つの図で示す。5段階フローは維持。|
|4P|NGは旗、OKは吹き出し→旗|目標だけと、背景から目標へつながる違いを比較。枠内下部に小さく配置し、説明や新しい文言は追加しない。|
|5P|ハート・人物・吹き出し・旗|過去の愛情、現在の状態、言われた出来事、未来の目標を読む前に見分ける。OKの4写真は原本・位置・大きさも維持。|
|6P|ノートと変化の道筋|ただの記録と、変化を追うプロセスの違いを示す。同じサイズ・位置に揃え、本文サイズは維持。|
|8P|運動・注意・再挑戦|3段階の役割を補足。写真と既存の矢印を主役のまま、ラベル近くに小さく配置。|
|10P|グラフ入り虫眼鏡|右側が原因を探し、次の改善につなげる場所だと示す。左側5行はそのまま。|
|11P|旗・ハート・気づき・循環・検証|目標、共感、出来事からの発見、継続、改善を区別。左のピンク縦線と比較し、競合しないアイコンだけを採用。|

全アイコンは #DE5C84、細く丸みのある線、透過背景。写真の加工なし。SVG原本とPPTX用PNGをiconsに保存。文字追加なし・文章削除なし・文字サイズ縮小なし。3P上部、6P本文、11Pの本文開始位置だけ、絵と重ならない範囲で調整。既存のタイトル点線と上下グラデーションは保持。

## 検証

- 全11枚。変更スライドは3P・4P・5P・6P・8P・10P・11Pのみ。
- 1P・2P・7P・9PはHTMLセクション・PPTXスライドXML・PNGバイト・PDF描画が元版と一致。
- 全ページの文言と文字サイズが元版と一致。読点なし。
- 全写真のバイト・位置・サイズが元版と一致。
- 1440×810で対象7ページを画像化して目視確認。文字の横方向はみ出しなし。PPTXから独立にPDF変換し、全文字が描画されることを確認。
- 試作の評価：3Pの意味関係、5P・11Pの項目の見分けが視覚的に補助された。4P・8Pは既存情報量が多いため、アイコンは小さな補助に留めた。アイコン追加による学習効果は利用者評価前であり、見やすさ比較の素材として扱う。
