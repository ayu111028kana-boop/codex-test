## ファイル
PowerPointは編集可能な文字・図形と、加工していない元写真で構成。全11ページに講師用ノートを収録し、同じ内容をMarkdownでも添付。
PDF・PNGは閲覧用。HTMLはダウンロード後ChromeやEdgeで開く。左右端クリック、矢印キー、Home/Endでページ送り。Fで全画面。
PowerPointの表示をそろえる場合は同梱Zen Maru Gothic Boldフォントをインストール。
