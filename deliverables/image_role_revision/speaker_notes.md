# 2P

目次は5章。プロセスエコノミーの考え方、ゴールと共感の入口、台本の組み立て方、リアルな過程の見せ方、複数投稿で物語をつなぐ・まとめ。最後に投稿後の数字を見て改善する方法も扱う。

# 3P

プロセス型は、ただ挑戦の過程を見せるだけではない。初見の視聴者はまだ発信者本人に興味がない。まず「私も同じ」「分かる」と思える入口を作る。スタート地点からゴールまでの変化を見せることで、日々の投稿が一つの物語になる。共感→自分事化→続きが気になる→応援したくなる→ファンになる。

# 4P

ゴールがあるから、その途中が物語になる。スタート地点とゴール地点を明確にする。「100日後に水着を着たい」だけでは、自分には関係ないと感じる人もいる。なぜそのゴールを目指すのか、背景や悩みまで見せる。ゴールや過程そのものに興味を持ってもらえるかも考える。

# 5P

過去は夫が「可愛い」と言ってくれるほど仲がよかった。現在は家庭を一緒に回す戦友のような関係。家族でアニメを見ていた時にセイウチに似ていると揶揄され、ショック・悔しさ・寂しさを感じた。「私の目標を見て」ではなく「あなたにもこんな悩みない？」という入口を作る。未来・ゴールのカードはこのページに置かず、9Pで説明する。

# 6P

日記は「今日は夜ごはんをゆで卵にした。1週間頑張る」という行動の報告で終わる。プロセスは、夜になると疲れて何もしたくない、でも痩せたいという悩みとゴールから始まる。自分だけ別のダイエットごはんを作るのは正直めんどくさい。そこで夜ごはんをゆで卵に変えたらどうなるか1週間検証する。悩み・ゴール・挑戦・続きがあるから「どうなる？」が生まれる。これは本人の投稿内容を台本構成として扱う例。

# 7P

1本のリールの型は、①冒頭：悩み・興味を引く、②共感・現在地：「私も」と思ってもらう、③挑戦：何をするのか見せる、④過程・結果：リアルな変化を見せる、⑤次の展開：続きを見る理由を作る。
あゆみんの実例「ゆで卵1週間検証」は挑戦宣言の投稿。
①冒頭：「1週間、夜ご飯をゆで卵3個に置き換えたらどれだけ痩せる？」
②共感・現在地：「家族5人分のごはんを作るだけでも白目。自分のためだけにダイエットメニューを作るなんて無理ゲー…」
③挑戦：「子どもたち用にいつも大量に茹でてるゆで卵ならできそう！夜ご飯をゆで卵3個にして1週間検証」
⑤次の展開：「どれくらい変化あるんか結果が気になる人はフォローして待っててな〜」
この時点では④過程・結果はまだない。毎回①〜⑤を全部使う必要はない。挑戦宣言・途中経過・結果発表など、投稿の目的に合わせて必要な要素を使い分ける。
台本を作る前に「この投稿の目的は？」「誰に届ける？」「一番伝えたいことは？」を考える。

# 8P

HIITは短い運動と休憩を繰り返すトレーニング。ここでは効果を紹介するのではなく、予定外の出来事をどうコンテンツに変えたかを説明する。
成功した姿だけでなく、迷い・失敗・感情・小さな変化・思うようにいかなかった日・途中経過もコンテンツになる。
実例：HIITを1週間検証したところ−2.9kgという変化があった。しかし途中で風邪をひき、喉が痛くて食事量も減った。そのため「−2.9kgはHIITだけの結果ではない」と正直に伝えた。HIITの効果として数字を断定しない。
予定通りの検証にはならなかったが、「このまま終わるのはもったいないし悔しい」という感情を「もう1週間再チャレンジする」という次の投稿へつなげた。
出来事を報告するだけなら日記。「そこから何を伝えられる？」「次にどうする？」まで考えるとコンテンツになる。
完璧に見せすぎないことで「この先どうなる？」が生まれる。

# 9P

アカウント全体のゴールは「痩せて夫とデートへ行く。また『可愛い』と言ってもらう」。ゆで卵1週間検証、別のダイエット検証、結果発表、次の挑戦へと投稿をつなげる。一つずつ独立していても、すべてが同じゴールへ向かう物語の途中になる。1本の投稿ですべてを完結させなくてもよい。複数投稿が同じゴールにつながることで「次も見たい」が生まれる。

# 10P

このページは今後初心者が分析するときに使う考え方・チェック基準。あゆみんの実分析を行った事例ではない。
投稿する→数字を見る→原因を考える→次の投稿で改善する。
再生数が伸びないなら、冒頭の悩みやテーマがターゲットに合っていたかを考える。
再生されても途中で離脱されるなら、前置きの長さや続きを見たくなる展開を確認する。
共感コメントが多くてもフォローが増えないなら、今後のゴールやフォローする理由が伝わっているかを考える。次の投稿では挑戦のゴールや今後の検証を明確にする、という仮説を立てる。
経過報告の反応が弱ければ、視聴者にとっての発見・見どころを確認する。
特定テーマだけ反応が良ければ、どんな悩み・切り口が響いたのか考える。
数字が悪いことは投稿全部がダメという意味ではない。「なぜ？」「次は何を変える？」という仮説を立てる。仮説を原因と断定しない。1投稿だけで判断せず、投稿数がたまってから傾向を見る。具体的な投稿数の基準はここでは設定しない。

# 11P

まとめ：①物語のゴールと共感の入口を決める。②ただの日記ではなく、この先どうなると思える挑戦にする。③日常の失敗や変化も、そこから何を伝えられるかに変換する。④一つのゴールに向かって複数投稿をつなげる。⑤投稿して終わりではなく、数字を見る→仮説を立てる→次で改善する。「私の挑戦を見て」ではなく「あなたにもこんな悩みない？」から始める。その先に共感→自分事化→続きが気になる→応援→ファン化が生まれる。
