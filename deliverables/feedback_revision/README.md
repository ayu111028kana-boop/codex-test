# フィードバック修正版（全11枚）

- 1枚目：表紙写真を削除し、アイコン・タイトル・講師名を中央へ再配置。
- 2枚目：資料全体を5項目で紹介する目次を追加。
- 5枚目（旧4枚目）：過去・現在の文章ボックス左側のピンク縦線2本を削除。背景、中央揃え、写真3枚、ゴール文を維持。
- 全ページ：右下のページ番号を現在ページ / 11へ更新。HTMLの最終ページ移動・表示数も自動化。
- 既存本文、改行、ゴール文は変更なし。残す写真6点は元PNGのバイト列と一致。
- 指摘対象外の囲み枠、色、写真、レイアウトは維持。

## 使用方法
HTMLはダウンロード後にChromeやEdgeで開いてください。左右端クリックまたは矢印キーでページ送り、Home/Endで先頭/末尾、Fで全画面です。
PowerPointの文字・図形は編集可能です。表示をそろえる場合は同梱のZen Maru Gothic Boldフォントをインストールしてください。
PDFと全ページPNGは閲覧用です。
